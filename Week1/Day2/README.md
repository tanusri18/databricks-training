# Day2 SQL Queries 

This Day2 Folder contains SQL table creation scripts and SQL queries for practicing basic to intermediate SQL concepts using an Employee database.

## Files Included

### 1. Table.sql
This file contains:
- CREATE TABLE statement
- INSERT INTO statements

It creates an Employees table with the following columns:
- emp_id
- emp_name
- department
- salary
- city
- experience

### 2. Queries.sql
This file contains 55 SQL queries covering different SQL concepts such as:
- SELECT statements
- WHERE clause
- Aggregate functions
- GROUP BY
- HAVING clause
- ORDER BY
- LIMIT
- DISTINCT
- Logical operators
- IN / NOT IN
- BETWEEN
- LIKE operator

## Database Used
MySQL / SQL Compatible Database

## SQL Concepts Covered

- Data Retrieval
- Filtering Records
- Aggregate Functions
- Grouping Data
- Sorting Data
- Pattern Matching
- Conditional Operators
- SQL Clauses
